# 词穹 V2.0 分阶段实施计划

每个阶段单独提交并保留回滚点；阶段验收通过后再进入下一阶段。

## Phase 1：数据基础与视觉系统

- 先建立 `schemaVersion`、安全存储适配器、V1 无损迁移和本地日期工具。
- 抽离可测试的复习调度函数和统计函数。
- 建立颜色、字体、间距、圆角、阴影和动画令牌。
- 建立 GlassCard、BentoGrid、ProgressRing、StatCard、CalendarCard、VocabularyCard、ReviewCard、PrimaryButton、EmptyState、LoadingState。
- 保留现有 UI 作为对照，不改变用户数据。

验收：迁移测试、日期边界测试、调度测试和生产构建全部通过。

## Phase 2：首页升级

- 建立首页、词库学习、复习计划、学习记录四个真实页面状态。
- 添加浮动导航、Hero 和真实数据驱动的 Bento Grid。
- 接入今日计划、复习、词库、收藏、错词和设置入口。
- 接入用户提供的雪山湖泊原图，输出 AVIF、WebP 和兼容格式。

验收：首页所有按钮可达真实功能；统计来自本地数据；移动端无横向滚动。

## Phase 3：学习与复习体验

- 拆分三轮训练会话并持久化当前位置。
- 统一“不认识 / 模糊 / 已掌握”结果模型。
- 复习任务卡可直接进入答题；完成页展示真实正确率、错词、用时和下次安排。
- 不增加词库不存在的例句、搭配、派生词或词性。

验收：中断恢复、刷新恢复、错误重试、重复提交和同日复习均有测试。

## Phase 4：日历与统计

- 实现完整月历、月份切换、返回今天和日期详情。
- 记录有效学习事件、任务完成状态、正确率、学习时长和复习次数。
- 实现连续与最长连续学习天数，排除未来日期和未结束当天的错误中断。

验收：跨月、跨年、本地午夜、空数据和部分完成场景测试通过。

## Phase 5：计划与数据安全

- 加入每日新词、每日时间、每周学习天数设置。
- 计划计算同时考虑复习负载、历史速度和未完成任务上限。
- 完整导出统一快照；导入前校验、备份并明确选择合并或覆盖。

验收：旧数据迁移、损坏文件、重复导入、考试日期调整和计划重排测试通过。

## Phase 6：移动端与性能

- 验证 375、390、430、768、1024、1440px。
- 优化移动键盘、弹层、日历和学习卡片。
- 拆分非关键页面、缓存词库、压缩图片并降低低性能设备的毛玻璃成本。

验收：无水平溢出；核心学习操作不被键盘遮挡；减少动态效果设置有效。

## Phase 7：独立测试部署

- 从 `v2-development` 部署独立预览，不修改生产分支。
- 在 EdgeOne 验证构建、缓存、HTTPS、域名与中国大陆网络。
- 明确 ICP、DNS、回滚和旧域名数据迁移流程。

## Phase 8：最终验收

- 全量功能、视觉、数据和异常测试。
- 输出桌面和手机截图、问题清单、部署文档、文件清单与保留功能说明。
- 验收通过后，才决定是否把 V2 合并到正式生产分支。
